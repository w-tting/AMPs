## Rosetta calculations 

The `CecA.pdb` structure was generated by homology modeling using SWISS-MODEL. To calculate ΔΔG, use this structure and follow the procedures and commands provided in the `Rosetta ddg_monomer command.txt` file to run the Rosetta `ddg_monomer` program.

## Requirements

Two separate Conda environments are recommended for dataset splitting and model training/evaluation.

### Environment 1: Dataset Splitting

This environment is used for sequence-similarity-aware dataset partitioning with GraphPart, MMseqs2, and EMBOSS Needle.

Create and activate a Conda environment:

```bash
conda create -n amp_split -c conda-forge -c bioconda python=3.10 pandas biopython emboss mmseqs2 pip -y
conda activate amp_split
```

Install GraphPart:

```bash
python -m pip install graph-part==1.0.2
```

### Environment 2: Training and Evaluation

This environment is used for CNN model training, fine-tuning, sequence generation, and performance evaluation.

Create and activate a separate Conda environment:

```bash
conda create -n amp_model python=3.7 -y 
conda activate amp_model
   ```
   
From the project's root directory, install the required Python packages:

```bash
python -m pip install -r requirements.txt
```

## Data

The `data` directory contains the datasets used for model training. In each file, the `sequence` column contains peptide sequences composed of standard amino acids, while the `value` column contains the base-10 logarithm (`log10`) of the minimum inhibitory concentration (MIC), which represents antibacterial activity.

`GRAMPA.csv` contains a database of peptides and their antimicrobial activities against various bacterial species. The `has_unusual_modification` column indicates, with `TRUE` or `FALSE`, whether a peptide contains modifications other than C-terminal amidation.

`ecoli.csv` is derived from `grampa.csv` and contains antimicrobial peptide sequences with no modifications other than C-terminal amidation, together with their activities against *Escherichia coli* (*E. coli*).

`nonAMP.csv` contains sequences obtained from the UniProt database. These sequences have no antibacterial activity and are assigned a maximum activity value of 4.

`SM.csv` and `RM.csv` contain CecA variants generated through saturation mutation and random mutation, respectively. These datasets are used for model fine-tuning.

### Data curation and Sequence-similarity-aware partitioning

1. Remove duplicate sequences from `nonAMP.csv`, then remove sequences that conflict with those in the antimicrobial peptide (AMP) dataset. Merge the curated data to obtain `train_clean.csv`.

2. From the `data` directory, run the following command to create the `split_data` directory and prepare the sequences for similarity-aware partitioning:

   ```bash
   python ../script/prepare_graphpart.py prepare train_clean.csv
   ```

3. To accelerate sequence-similarity-aware partitioning, run GraphPart in MMseqs2–Needleman–Wunsch mode using the following command. However, this approach may not identify all highly similar sequence pairs. Therefore, the resulting train–test split is subsequently validated using EMBOSS Needle.

   ```bash
   graphpart mmseqs2needle --fasta-file split_data/curated.fasta --threshold 0.6 --out-file split_data/graphpart_assignments.csv --labels-name label --test-ratio 0.1 --recompute-threshold 0.4 --denominator-mmseqs longest --denominator-needle full --threads 8
   ```

4. Export the partitioning results to generate `train.csv` and `test.csv`:

   ```bash
   python ../script/prepare_graphpart.py export split_data/graphpart_assignments.csv
   ```

5. Calculate the maximum sequence identity between the training and test sequences using EMBOSS Needle:

   ```bash
   python ../script/max_identity.py
   ```

   Based on the results in `data/output/max_identity_test_vs_train.csv`, remove from `test.csv` any sequences with greater than 60% identity to a training sequence. Save the remaining sequences as `test_final.csv`, the final test dataset.

## Scripts

`utils.py` defines variables and constants; provides functions for sequence encoding and converting model-predicted scores into prioritization percentiles; and evaluates Spearman and Pearson correlations on the held-out test sequences containing only AMPs. These utilities are imported and used by other scripts.

`prepare_graphpart.py` organizes and prepares sequences for GraphPart partitioning and exports the results after partitioning.

`max_identity.py` calculates the maximum sequence identity after GraphPart partitioning using EMBOSS Needle.

`model.py` defines the neural network architecture and provides an example of how to run the model. 

`hyperparameters.py` performs a cross-validation-based search for the best hyperparameter combination. The parameters to be optimized can be modified in the `param_grid` dictionary.

`fine_tune.py` fine-tunes the base model using `SM.csv` and `RM.csv` and saves the resulting model in the `model` directory. To fine-tune the model using a different dataset, change the input CSV filename in the script.

`sequence_generation.py` uses the saved model in the `model` directory to guide the generation of new AMP candidates through simulated annealing and to predict their scores.

`performance.py` generates scatter plots comparing reference activity labels with model-predicted scores.

`properties.py` uses Modlamp and Biopython to calculate physicochemical properties for a list of sequences and visualize the results.

`sequence_space.py` uses t-SNE for dimensionality reduction and plots the latent sequence space based on a sequence similarity matrix.

`subsampling.py` performs size-matched subsampling and label-permutation analyses using `SM.csv` and `RM.csv`.

`baseline.py` trains amino-acid-composition-based Ridge regression and physicochemical-property-based RBF-SVR baseline models for candidate prediction and comparison with the CNN model.

## Model
 
 To fine-tune the model, run the following command in the `script` directory:

```bash
python fine_tune.py
```

The `model` directory contains a pretrained model that can be used to predict activity scores and generate new AMP candidates. To generate sequences, run in the `script` directory:

```bash
python sequence_generation.py
```
